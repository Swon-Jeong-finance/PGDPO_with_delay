## 현재 인증 상태 (이 스냅샷에서 재현)
- pytest: Torch 환경 fast 187 passed + slow 1 passed (총 188)
  실행: python -m pytest tests -q -m "not slow"
        python -m pytest tests/test_stage1_p1.py::test_training_reduces_objective_smoke -q
- verify: python main.py verify --all  → P1/P2/P3/P4 ALL PASS
- Stage-I end-to-end: P1-U smoke 3 seeds에서 worker → seed artifact atomic
  publish → per-seed/95% CI 집계 → 동일 fingerprint resume를 재현했다.
- P3 full 인증: python main.py verify --problem p3 --full
  → `outputs/verify/p3/current-full.json`이 가리키는 immutable bundle에
    p3r_hjb_value.npz(전체 시간축 V), p3r_hjb_policy.npz,
    p3r_certification.csv, p3r_hjb_residual.csv,
    p3d_ce_nmpc_certification.csv + manifest(verify_tier/protocol/seeds/API)
  → 계산·gate·파일쓰기 중 하나라도 실패하면 기존 current-full bundle은 불변
- P4 full 인증: python main.py verify --problem p4 --full
  → `outputs/verify/p4/current-full.json`이 가리키는 immutable bundle에
    p4_oracle.npz(Pval/Gol/Pi/F/Lambda/recovery curvature),
    p4_certification.csv, p4_feasibility.json,
    p4_diagnostic_paths.npz(p_cur/p_nxt/q/zeta/recovery targets 포함)와
    manifest/config를 저장한다.
  → exact `u_rec_pnxt`는 machine precision으로 oracle action을 복원하며,
    `u_rec_pcur`의 canonical full-bank finite-grid floor는
    RMSE `0.006983`, action nRMSE `0.6837%`다. 이는 estimator/PGDPO 오차가
    아니라 좌표 정렬(discretization-alignment) 진단이다.

## Stage-I multi-GPU 실행
- `--devices cuda:0,cuda:1,...`에 GPU당 subprocess 하나를 배정하고, 먼저
  끝난 슬롯에 다음 seed를 즉시 넣는다.
- smoke는 `--protocol p1_u_smoke`, P1-U Phase-B production은
  `--protocol p1_u`를 사용한다.
- production 입력은 oldest-to-newest `(B,H+1,3)`의
  `[state, kh/T, relative_lag]`이고, 모델은 hidden 256의 2-layer LSTM 뒤
  `Linear-Tanh-Linear` head를 사용한다. Protocol은 `lr=5e-5`,
  `val_batch=1024`, evaluation `Np=50000`을 동결한다.
- validation 시점의 로그에는 `J_train`, `J_val`을 함께 출력하고 새 best에는
  `*`를 붙인다. Scheduler는 실행 중 terminal에 seed/device prefix로 전달하되
  seed별 `run.log` 원문은 보존한다.
- seed별 checkpoint/metrics/trace/log와 learned metric의
  mean/SD/Student-t 95% CI가 자동 저장된다. 중단 후 동일 명령에
  `--resume`을 붙이면 fingerprint가
  일치하고 manifest/config/checkpoint 교차검증까지 통과한 COMPLETE seed만
  재사용한다. 필수 metric에 NaN/Inf가 있으면 해당 seed는 FAILED다.
- seed CI는 공통 evaluation bank에 조건부인 **training-seed 변동성**이다.
  각 정책의 paired-path Monte Carlo SE(`dJ_se`)와 별개이며, 공통 oracle
  diagnostic에는 가짜 zero-width seed CI를 출력하지 않는다.
- 상세 명령과 artifact 계약:
  `docs/decisions/PGDPO_STAGE1_MULTIGPU_RUNNER_20260807.md`.

## Stage-II 공통 코어 상태
- raw `p_cur/zeta/Pi/sigma_ref`에서 `q_anc`를 먼저 만든 뒤
  `p/q_anc/sym(Pi)`를 독립 projection하고 `zeta`를 대수적으로 복원하는
  순서가 하나의 NumPy/Torch-preserving implementation으로 고정됐다.
- P1-U unconstrained 및 P1-C scalar-box recovery/KKT adapter가 연결됐다.
- numerical projection radii는 아직 paper/config에서 동결되지 않아 임의로
  넣지 않았다. 현재 제공되는 no-op block은 명시적 `identity-audit` 용도이며,
  P1 adapter는 projector 누락(`None`)을 거부한다.
- P1 output schema 2는 paired objective 산술과 CRN을 검증하고, Stage-II
  recovery/holdout bank의 ID·seed 독립성 및 projection mode/API/hash를 강제한다.
- 자세한 구현/보류 경계는
  `docs/decisions/PGDPO_STAGE2_common_core_20260807.md`에 기록한다.

## P3의 확정된 비딥러닝 범위
- P3-R: controlled-diffusion 2D HJB reference와 grid/domain/Bellman/policy
  certification을 동결한다.
- P3-D: 정확한 truncated-Gamma kernel을 쓰는 CE-NMPC proxy 하나를 유지하고,
  lookahead/iteration/tolerance는 YAML에 고정한다. 독립 holdout에서
  CE deterministic open-loop subproblem box-KKT, raw/deployed constraint,
  optimizer health, optimizer/decision runtime, optimizer/total
  objective-gradient evaluation count를 분리해 저장한다.
- P3-R/P3-D 직접 비교, initial-law matching 실험, no/frozen-memory ablation,
  local perturbation, budget frontier, scenario 수 sweep은 하지 않는다.
- scenario-NMPC는 CE-NMPC가 명백히 불충분할 때만 추가하는 contingency다.

## P4의 확정된 비딥러닝 범위
- signed control, 독립 `W_Q/W_alpha`, pre-trade realised-fill impact의 main
  instance만 유지한다. Eq. (78)의 causal discrete impact row를 사용하며
  current action은 impact에서 제외한다.
- exact same-grid generalized stochastic Riccati의 `Pval/Lambda`와 detached
  fixed-control `Gol/Pi`를 분리한다. q-form/recovered-control target에서는
  `p_cur`와 `p_nxt`도 분리해 저장한다.
- V1 calibration은 causal algebra, 두 curvature positivity gate, MC-vs-value,
  terminal inventory/overshoot/round-trip, history/signal visibility gate를
  통과해 동결됐다.
- P4 NMPC, box-constrained/correlated-noise variants, scenario sweep은 만들지
  않는다. P4의 최종 본문 포함 여부는 이후 learned-method pilot에서 결정한다.
